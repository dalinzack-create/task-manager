# 📝 Personal Task Manager

A responsive, single-page web application for managing daily tasks, featuring built-in UI theme toggling and offline data persistence. 

## Features
* **Local Data Persistence:** Leverages the browser's native `LocalStorage` API to ensure tasks are securely saved across sessions without requiring a backend server.
* **Theme Customization:** Integrated dark mode functionality for an optimal user experience, accessible via a streamlined UI toggle.
* **Responsive Design:** A clean, modern interface styled with Tailwind CSS to work seamlessly across desktop and mobile devices.
* **Zero-Reload State Management:** Dynamic DOM updates powered entirely by Vanilla JavaScript for a fast, app-like feel.

## Tech Stack
* HTML5 
* Vanilla JavaScript
* Tailwind CSS (via CDN)
* LocalStorage API# 📝 Cloud-Synced Task Manager
