# 📝 Cloud-Synced Task Manager

A responsive, single-page web application for managing daily tasks, featuring a built-in dark mode toggle and data persistence. 

## Features
* **Theme Toggling:** Integrated light and dark mode functionality for optimal user experience.
* **Data Persistence:** Tasks are securely saved so no data is lost when the browser is closed or refreshed.
* **Responsive UI:** Clean, modern interface designed to work seamlessly across desktop and mobile devices.
* **Zero-Reload State Management:** Asynchronous DOM updates powered by Vanilla JavaScript.

## Tech Stack
* HTML5 
* Vanilla JavaScript
* Tailwind CSS (via CDN)
* Firebase
